# 一亩三分地 黑话词典

这份词典专门覆盖一亩三分地论坛的圈内梗、emoji 化绰号、中英混用术语。

⚠️ **使用纪律**（重要）：
1. 看到帖里的任何**公司绰号 / emoji / 缩写**，**先来这份词典查一遍**，不要靠推理猜
2. 尤其是 emoji 化的厂名（🦑、🍎 等），靠 WebSearch 几乎搜不到，词典是唯一可靠来源
3. 词典里没有的术语，再 WebSearch 或推理
4. 如果同一术语词典里给了多个含义（如"红厂"），结合上下文判断

## 离职 / 裁员 / PIP

| 黑话 | 含义 |
|---|---|
| PIP | Performance Improvement Plan，"绩效改进计划"。**绝大多数情况是软性裁员前奏**，进了 PIP 基本就要找下家 |
| ER / Employee Relations | 员工关系 HR 部门。HR 升级到 ER 通常意味着公司在准备炒你 |
| layoff / 裁员 / 毕业 | 公司主动裁员（n+x 包，n=工龄）|
| 拿包走人 / 拿 package 走 | 拿了 severance package 离开，相对体面 |
| 包 / package | severance / 补偿包 |
| GVSA | Google Voluntary Separation Agreement，自愿离职协议（拿包走）|
| stack ranking | 强制排名，每年一定比例员工被打低分 |
| MIP / Meets | Meta/Google "达标"评级，连续 Meets 可能是裁员目标 |
| Below / Below Expectations | 低于预期，PIP 候选 |
| fire / 开 | 直接开除 |
| RIF | Reduction in Force，正式裁员术语 |
| WARN | WARN Act，美国大规模裁员法律通知期 60 天 |
| garden leave | 离职后还在带薪假期，期间不能加入竞品 |
| 非自愿离职 | involuntary separation |
